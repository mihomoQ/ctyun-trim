### 改进

- Prepare 支持处理经过身份校验的 `TaskAgentDetect` 进程占用 Cloudbase 配置文件的情况。
- 加强 Cloudbase 账户、服务和配置文件的关联检查，调整清理顺序，避免提前删除仍在使用的账户或配置文件。

### 修复

- 修复部分包含 `loaded` 的错误信息被诊断结果误标为成功的问题。

### 更新说明

Apply 仍要求 Cloudbase 配置文件已卸载。若重启后仍提示占用，请升级到 0.1.5 或更新版本，不要强制卸载用户注册表。

### Improved

- Prepare can now handle a Cloudbase profile held by an identity-validated `TaskAgentDetect` process.
- Strengthened association checks among the Cloudbase account, services, and profile, and adjusted the cleanup order to avoid prematurely deleting an account or profile that is still in use.

### Fixed

- Fixed some error messages containing `loaded` being incorrectly classified as successful diagnostic results.

### Notes

Apply still requires the Cloudbase profile to be unloaded. If it remains in use after a reboot, upgrade to version 0.1.5 or later instead of forcibly unloading the user registry hive.
