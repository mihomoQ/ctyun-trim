### What's changed

- **Added:** A repair for the Start menu's Shut down and Restart options hidden by preinstalled policies, included in the cleanup workflow by default.
- **Added:** `Restore-PowerMenu.cmd` to repair the power menu separately on systems that have already been trimmed.
- **Improved:** Original power-menu values are backed up separately before making changes. Repeated runs do not repeat the changes, and other ReviOS settings are preserved.
- **Improved:** Domain, MDM and local Group Policy checks prevent the repair from overwriting managed power-menu settings.

> [!NOTE]
> On an already-trimmed system, run `.\Restore-PowerMenu.cmd -Force` from an elevated terminal; there is no need to run Apply again. This command does not shut down or restart Windows.

### 更新内容

- **新增：** 恢复开始菜单中被预装策略隐藏的“关机”和“重启”选项，精简流程默认包含此修复。

- **改进：** 增加域、MDM 和本地组策略检查，避免覆盖受管理的电源菜单设置。

> [!NOTE]
> 已完成精简的系统，在管理员终端运行 `.\Restore-PowerMenu.cmd -Force` 即可，无需重新执行 Apply。此命令不会直接关机或重启。
