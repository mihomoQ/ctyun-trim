### Added

- Restored the Start menu's Shut down and Restart options hidden by preinstalled policies. The cleanup workflow now includes this repair by default.
- Added `Restore-PowerMenu.cmd` to repair the power menu separately on systems that have already been trimmed.

### Improved

- Added separate backups of the original power-menu values before making changes. Repeated runs do not repeat the changes, and other ReviOS settings are preserved.
- Added domain, MDM and local Group Policy checks to avoid overwriting managed power-menu settings.

### Notes

On an already-trimmed system, run `.\Restore-PowerMenu.cmd -Force` from an elevated terminal; there is no need to run Apply again. This command does not shut down or restart Windows.
