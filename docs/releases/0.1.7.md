### 新增

- 新增 `Trim.cmd` 单命令入口，自动衔接准备、精简和重启后的续跑，无需手动填写 RunId。

### 改进

- 批量停止待移除组件的进程，减少逐个等待，并补查清理期间重新启动的进程。
- 已完成的精简任务再次运行时只进行验证，不重复删除组件。

### 修复

- 修正部分进程已退出后仍保留的待处理记录和重启提示。
- 验证时区分已确认的空目录、打印初始化日志与实际组件残留，未知文件仍会报告失败。

### 更新说明

在管理员终端运行 `.\Trim.cmd -Force`。提示重启后，重启并重复同一条命令即可；脚本不会自动重启。

### Added

- Added `Trim.cmd` as a single entry point for preparation, cleanup and resuming after a reboot, without entering a RunId manually.

### Improved

- Processes belonging to components being removed are now stopped in batches, reducing per-process waits. Additional checks detect processes that restart during cleanup.
- Re-running a completed cleanup only verifies the result; it does not remove components again.

### Fixed

- Corrected stale pending records and reboot prompts left behind after some processes had already exited.
- Verification now distinguishes recognized empty directories and printer initialization logs from actual component remnants. Unknown files still cause verification to fail.

### Notes

Run `.\Trim.cmd -Force` from an elevated terminal. When prompted, restart Windows and run the same command again. The script does not restart Windows automatically.
