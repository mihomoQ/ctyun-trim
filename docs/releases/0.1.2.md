### Improved

- Added compatibility for the confirmed self-signed certificate used by VirtIO `BalloonService`, preventing its untrusted certificate chain from blocking the trim workflow. Only files matching the built-in validation values are accepted.
- Strengthened integrity validation for preserved core components and release packages without installing a new trusted root certificate on the system.

### Fixed

- Fixed architecture information appearing as Unknown in diagnostics on some localized systems.
- Fixed the exit status when a read-only diagnostic export fails.
