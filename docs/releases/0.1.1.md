### 新增

- 新增可选 `-Diagnostic` 参数，可导出用于排查问题的诊断包，不改变原有精简流程。
- 诊断包记录预检查、执行结果和重启状态，支持关联已有 RunId。
- 提供诊断包 SHA-256 校验文件；导出内容使用固定字段并过滤敏感信息，不包含原始运行备份。

### 更新说明

诊断包不会自动上传。分享前请自行检查；运行精简前请保留可恢复的系统快照。

### Added

- Added the optional `-Diagnostic` parameter for exporting a troubleshooting bundle without changing the existing trim workflow.
- The diagnostic bundle records preflight checks, execution results, and reboot state, and can be associated with an existing RunId.
- Added a SHA-256 checksum file for the diagnostic bundle. Exports use a fixed field set, filter sensitive information, and exclude raw run backups.

### Notes

Diagnostic bundles are never uploaded automatically. Review a bundle before sharing it, and keep a recoverable system snapshot before running the trim workflow.
