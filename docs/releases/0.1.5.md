### 新增

- 处理重启后 cloudbase-init 配置文件持续占用的情况：先停用已核验服务的自动启动，再提示重启后续跑。
- 提供独立的 Cloudbase 配置文件占用检查工具，便于定位阻止清理的进程。

### 修复

- 修复计划任务重新生成后，备份可能覆盖旧任务记录的问题。

### 已知问题

重启后目录重新生成仍可能导致隔离目标冲突，此问题已在 0.1.6 修复。新部署请使用较新版本。

### Added

- Added handling for cloudbase-init user profiles that remain loaded after a reboot: disable automatic startup of the verified service, then request a reboot before resuming cleanup.
- Added a standalone Cloudbase profile occupancy checker to help identify processes blocking cleanup.

### Fixed

- Prevented backups of recreated scheduled tasks from overwriting backups associated with earlier task records.

### Known Issues

Directories recreated after a reboot may still cause quarantine destination conflicts. This is fixed in 0.1.6. Use a newer version for new deployments.
