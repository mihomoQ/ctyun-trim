# 历史版本归档

0.1.5 和 0.1.6 于 2026-09-05 补充发布。附件均为当时保留的原始构建，未用新版代码改名替代。
这些版本用于历史对照，新部署请使用[发布页](https://github.com/mihomoQ/ctyun-trim/releases)中的较新版本；不要在已有精简任务上降级。

| 版本 | 源码依据 |
| --- | --- |
| 0.1.5 | 标签指向原始提交 `c12efb541a09a995251db65b4df4102e2d7da625`；包内 31 个文件与该提交内容一致，仅部分文件换行符不同。 |
| 0.1.6 | 当时没有独立提交，修改后来随 0.1.7 提交。本次从原始安装包的 32 个文件建立源码归档 `7fd1b1ce6dc1dd81995f2818e4e097be8bbadc5a`，父提交为上述 0.1.5 提交。 |

0.1.6 的归档提交使用实际补档时间，不回填旧时间、不改写 main。它不是 0.1.7 的祖先，
因此 0.1.7 发布说明链接到固定版本的 CHANGELOG，而不把三点比较误作相邻版本的纯增量。
原始安装包的校验文件随对应 Release 附件提供。
